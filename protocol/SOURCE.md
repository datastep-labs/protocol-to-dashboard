# Source of the protocol

`usdm.json` is the protocol of the CDISC pilot study (LZZT: xanomeline TTS in mild to moderate Alzheimer's disease) as a
CDISC Unified Study Definitions Model (USDM 4.0) study definition: the structured protocol.

- From https://github.com/cdisc-org/360i, folder `data/protocol/LZZT/usdm`, file `CDISC_Pilot_Study_v4.json`,
  commit 714e220 (2026-03-30). MIT licence, Copyright (c) CDISC.
- Unchanged.

Sapling makes the plan's first draft from it (`sapling new`), and checks every quote of the plan against it.
